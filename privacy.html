Privacy Policy

The Non-Coder · Last updated 6 November 2026

The Non-Coder ("we") runs the Instagram account @noncoderhq, the YouTube channel @noncoderhq, and the website noncoder.unchurned.co. This policy explains what data our publishing tool ("NonCoder Publisher") uses.

What NonCoder Publisher does

NonCoder Publisher is a private tool used only by the owner of The Non-Coder to upload videos and captions to our own Instagram and YouTube accounts and to read basic performance statistics (views, likes, followers) for those accounts. It is not offered to the public and does not access anyone else's accounts.

Data we access

  • Access tokens for our own Instagram and YouTube accounts, stored only on the owner's computer (macOS Keychain).
  • Aggregate statistics about our own posts.

We do not collect, sell, or share personal data of viewers or followers. Google user data obtained through YouTube APIs is used only to publish and measure our own content, in line with the Google API Services User Data Policy.

YouTube API Services

NonCoder Publisher uses YouTube API Services to upload videos to our own YouTube channel (@noncoderhq) and to read statistics about our own videos. By using our YouTube content you are also subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Data accessed via YouTube API Services: our own channel's basic information (channel name and ID) and statistics for our own videos (views, likes, subscriber count). How it is used: only to publish our videos and create internal performance summaries. Storage: the OAuth refresh token is kept only in the owner's macOS Keychain; statistics are stored locally on the owner's computer and kept for up to 12 months, then deleted. Sharing: we do not share, sell or transfer any YouTube API data to third parties.

Revoking access and deletion: access can be revoked at any time via the Google security settings page at https://security.google.com/settings/security/permissions. When access is revoked, or on request to noncoderhq@gmail.com, all stored YouTube API data is deleted within 7 days.

Website

noncoder.unchurned.co is a static page hosted on GitHub Pages and served through Cloudflare. We do not use cookies or analytics. GitHub and Cloudflare may log basic request data under their own privacy statements.

Purchases

Digital products are sold through Topmate, which handles payments and buyer data under its own privacy policy.

Removing access / deletion

You can revoke NonCoder Publisher's access at any time via your Google Account permissions (myaccount.google.com/permissions) or Instagram settings. To request deletion of any data, email noncoderhq@gmail.com.
